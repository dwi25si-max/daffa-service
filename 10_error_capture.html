Error #1 RouteNotFoundException (Route [name] not defined)
Routing & Blade
Pesan Error: Symfony\Component\Routing\Exception\RouteNotFoundException: Route [login] not defined.
BEFORE (Penyebab Error) 
// routes/web.php:
Route::get('/auth', [AuthController::class, 'showLogin']);
// Rute tidak diberi name('login')!

// resources/views/partials/navbar.blade.php:
<a href="{{ route('login') }}">Login</a>
// Terjadi RouteNotFoundException karena route('login') belum didefinisikan.
AFTER (Solusi Perbaikan) 
// routes/web.php:
Route::get('/auth', [AuthController::class, 'showLogin'])
    ->name('login'); // Tambahkan ->name('login')

// resources/views/partials/navbar.blade.php:
<a href="{{ route('login') }}">Login</a>
// Berhasil! Laravel menemukan rute dengan nama 'login'.
Error #2 419 Page Expired (TokenMismatchException)
Security & Form POST
Pesan Error: 419 | PAGE EXPIRED (Illuminate\Session\TokenMismatchException: CSRF token mismatch.)
BEFORE (Penyebab Error) 
// resources/views/guest/login.blade.php:
<form action="{{ route('login.process') }}" method="POST">
    <!-- LUPA MENYEDIAKAN DIRECTIVE @csrf -->
    <input type="text" name="username">
    <input type="password" name="password">
    <button type="submit">Login</button>
</form>
// Request POST ditolak oleh middleware VerifyCsrfToken.
AFTER (Solusi Perbaikan) 
// resources/views/guest/login.blade.php:
<form action="{{ route('login.process') }}" method="POST">
    @csrf <!-- Tambahkan direktif CSRF token -->
    <input type="text" name="username">
    <input type="password" name="password">
    <button type="submit">Login</button>
</form>
// Request POST lolos verifikasi keamanan CSRF.

Error #4 MassAssignmentException (Add to fillable property)
Eloquent ORM & Model
Pesan Error: Illuminate\Database\Eloquent\MassAssignmentException: Add [first_name] to fillable property to allow mass assignment on [App\Models\Pelanggan].
BEFORE (Penyebab Error) 
// app/Models/Pelanggan.php:
class Pelanggan extends Model {
    protected $table = 'pelanggan';
    // Tidak mendefinisikan array $fillable!
}

// Controller:
Pelanggan::create($request->all());
// Eloquent memblokir mass assignment demi keamanan.
AFTER (Solusi Perbaikan) 
// app/Models/Pelanggan.php:
class Pelanggan extends Model {
    protected $table = 'pelanggan';
    protected $fillable = [
        'first_name', 'last_name', 'birthday',
        'gender', 'email', 'phone'
    ];
}
// Data berhasil disimpan via Pelanggan::create().
Error #5 MethodNotAllowedHttpException (Method not supported)
HTTP Method & Routing
Pesan Error: Symfony\Component\HttpKernel\Exception\MethodNotAllowedHttpException: The GET method is not supported for route auth. Supported methods: POST.
BEFORE (Penyebab Error) 
// routes/web.php:
Route::post('/auth', [AuthController::class, 'login'])->name('login.process');
// Hanya rute POST yang dibuat. Saat user membuka URL http://localhost:8000/auth
// via browser (GET request), Laravel menghasilkan error MethodNotAllowed.
AFTER (Solusi Perbaikan) 
// routes/web.php:
// Sediakan rute GET untuk menampilkan halaman form:
Route::get('/auth', [AuthController::class, 'showLogin'])->name('login');

// Dan rute POST untuk memproses kiriman data form:
Route::post('/auth', [AuthController::class, 'login'])->name('login.process');
Error #6 BindingResolutionException (Target class does not exist)
Controller & Namespace
Pesan Error: Illuminate\Contracts\Container\BindingResolutionException: Target class [AuthController] does not exist.
BEFORE (Penyebab Error) 
// routes/web.php:
<?php
use Illuminate\Support\Facades\Route;
// Lupa menulis: use App\Http\Controllers\AuthController;

Route::get('/auth', [AuthController::class, 'showLogin']);
// PHP tidak mengenali letak namespace class AuthController.
AFTER (Solusi Perbaikan) 
// routes/web.php:
<?php
use App\Http\Controllers\AuthController; // Import Controller
use Illuminate\Support\Facades\Route;

Route::get('/auth', [AuthController::class, 'showLogin']);
// Class Controller berhasil ditemukan dan di-resolve.
Error #7 ErrorException: Undefined variable $variable
Controller to View Passing
Pesan Error: ErrorException: Undefined variable $dataPelanggan (View: index.blade.php)
BEFORE (Penyebab Error) 
// PelangganController.php:
public function index() {
    $dataPelanggan = Pelanggan::all();
    return view('admin.pelanggan.index'); // Lupa mengirim variabel!
}

// index.blade.php:
@foreach($dataPelanggan as $item) // Error karena $dataPelanggan null
AFTER (Solusi Perbaikan) 
// PelangganController.php:
public function index() {
    $data['dataPelanggan'] = Pelanggan::all();
    return view('admin.pelanggan.index', $data);
    // Atau: return view('admin.pelanggan.index', compact('dataPelanggan'));
}
Error #8 Form Data Reset (Input Hilang Saat Validasi Gagal)
Validation & old() Helper
Problem: Ketika user mengisi form panjang dan salah satu validasi gagal, form kembali kosong melompong (tidak ada repopulate) dan tidak menampilkan pesan error.
BEFORE (Penyebab Masalah) 
// create.blade.php:
<input type="text" name="name" class="form-control">
<input type="email" name="email" class="form-control">
// Tanpa value="{{ old('...') }}" dan tanpa alert @error,
// user dipaksa mengetik ulang semua isian dari nol.
AFTER (Solusi Perbaikan) 
// create.blade.php:
<input type="text" name="name"
       value="{{ old('name') }}"
       class="form-control @error('name') is-invalid @enderror">
@error('name')
    <div class="invalid-feedback">{{ $message }}</div>
@enderror
Error #9 Password Plaintext & Class "Hash" not found
Security & Hashing
Pesan Error / Security Flaw: Error: Class "Hash" not found ATAU Password tersimpan mentah (plaintext) di tabel database sehingga gagal di-verify saat login.
BEFORE (Penyebab Error) 
// UserController.php:
User::create([
    'name' => $request->name,
    'email' => $request->email,
    'password' => $request->password, // Password mentah tanpa di-hash!
]);
// Berbahaya: password bocor jika database terekspos.
AFTER (Solusi Perbaikan) 
// UserController.php:
use Illuminate\Support\Facades\Hash; // Wajib import

User::create([
    'name' => $request->name,
    'email' => $request->email,
    'password' => Hash::make($request->password), // Enkripsi hash
]);

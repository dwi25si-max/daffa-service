📂 Tahap Awal

Kita akan membuat CRUD untuk Data Pelanggan dengan skema berikut:

1. Migration

Buat migration dengan nama create_pelanggan_table
php artisan make:migration create_pelanggan_table

File baru akan dibuat pada direktori database/migrations/

Penulisan nama file migration akan mempengaruhi nama table

Sesuaikan function up()

Penulisan variable harus memiliki skema column yang sama dengan desain table

public function up()
{
    Schema::create('pelanggan', function (Blueprint $table) {
        $table->increments('pelanggan_id');
        $table->string('first_name', 100);
        $table->string('last_name', 100);
        $table->date('birthday')->nullable();
        $table->enum('gender', ['Male', 'Female', 'Other'])->nullable();
        $table->string('email')->unique();
        $table->string('phone', 20)->nullable();
        $table->timestamps();
    });
}
  • $table->increments('pelanggan_id')

    Berfungsi untuk membuat kolom pelanggan_id sebagai primary key yang akan bertambah otomatis (auto increment) setiap kali data baru ditambahkan.

  • $table->timestamps()

    Secara otomatis menambahkan dua kolom, yaitu created_at dan updated_at, yang digunakan untuk mencatat waktu pembuatan dan pembaruan data.Pastikan selalu ada setiap membuat table baru!

Lakukan migration dengan perintah berikut:
php artisan migrate

Tabel baru dengan nama pelanggan akan di-create secara otomatis

Beberapa hal yang perlu diketahui tentang Migration

1️⃣ Migration = Versi dari Struktur Database

  • Migration bukan data, tapi definisi struktur tabel.
  • Tujuannya seperti version control untuk database, sehingga bisa tahu kapan tabel dibuat, diubah, atau dihapus.

2️⃣ Migration Dijalankan secara berurutan

  • Setiap migration adalah file PHP dengan nama format waktu:
    2025_10_13_123456_create_users_table.php
    • Nama ini membantu Laravel tahu urutan eksekusi migration.
  • Saat dijalankan, Laravel membaca semua migration yang belum pernah dijalankan

3️⃣ Migration Hanya Dijalankan Sekali

  • Setelah dijalankan, catatan disimpan di tabel migrations.
  • Meski merubah nama file migration, perubahan itu tidak otomatis dijalankan ulang kecuali di batalkan terlebih dulu.

4️⃣ Migration Bisa Dibatalkan

  • Gunakan:
    php artisan migrate:rollback

    untuk membatalkan 1 batch terakhir
    (1 batch = sekumpulan migration yang dijalankan melalui php artisan migrate).

  • Atau:
    php artisan migrate:fresh

    untuk hapus semua tabel lalu jalankan ulang semua migration dari awal

6️⃣ Migration Bisa Berisi up() dan down()

  • Fungsi up() berisi instruksi membuat/menambah kolom/tabel.
  • Fungsi down() berisi cara membatalkan perubahan tersebut (biasanya dropTable atau dropColumn).

7️⃣ Jangan modifikasi migration yang sudah di-migrate

  • Jangan asal ubah file migration. Kecuali sudah rollback
  • Lebih baik buat migration baru (misalnya add_phone_to_users_table) untuk menambah kolom baru.

8️⃣ Migration = Alat Kolaborasi Tim

  • Dengan migration, semua anggota tim bisa memiliki struktur database yang sama tanpa kirim file .sql manual.

2. Model

Buat model baru dengan nama Pelanggan
php artisan make:model Pelanggan

File baru akan terbentuk di app/models dengan nama Pelanggan.php

Sesuaikan isi model Pelanggan

$table → nama table

$primaryKey → nama kolom yang menjadi primary key

$fillable → kolom yang diperbolehkan untuk diisi

Jika fillable tidak ditentukan, maka data tidak akan bisa tersimpan

3. Controller

Buat resource controller dengan nama PelangganController
php artisan make:controller PelangganController --resource

Gunakan route yang mewakili seluruh function di PelangganController pada web.php

Dengan Route::resource , kita tidak perlu membuat route satu per satu untuk function index, create, show , edit, update , destroy karena laravel secara otomatis membuatkan route dengan alias :

pelanggan.index pelanggan.create pelanggan.show

pelanggan.edit pelanggan.update pelanggan.destroy

Aksi update dilakukan dengan berpindah ke halaman edit dengan membawa primary key data yang akan di perbaharui sebagai parameter.

1️⃣ Tambahkan tombol “Edit” pada kolom “Action”

Lalu paste pada tag <td> untuk tombol Edit disini:

2️⃣ Sesuaikan function edit()

Buat file edit.blade.php di resources/views/admin/pelanggan

Pada function edit(), ambil data Pelanggan berdasarkan id menggunakan findOrFail lalu kirim ke view admin.pelanggan.edit:

public function edit(string $id)
{
    $data['dataPelanggan'] = Pelanggan::findOrFail($id);
    return view('admin.pelanggan.edit', $data);
}

Pelanggan::findOrFail($id) → eloquent yang mengambil data sesuai $id lalu jika data tidak ditemukan maka secara otomatis menampilkan halaman Not Found

3️⃣ Salin seluruh isi create.blade.php → edit.blade.php

Lalu sesuaikan beberapa bagian berikut:

  • Judul: Tambah Pelanggan → Edit Pelanggan
  • Breadcrumb: Tambah Data → Edit Data
  • Action form: arahkan ke route berikut dan tambahkan parameter primary key 
    route('pelanggan.update', $dataPelanggan->pelanggan_id)

  • Tambahkan @method('PUT') setelah @crsf

    Hal ini dikarenakan function update() hanya menerima request PUT, jadi kita harus memodifikasi form nya dengan menambah @method('PUT')

  • Pastikan value di-set sesuai dengan data dari controller:
    • value="{{ $dataPelanggan->first_name }}"
    • value="{{ $dataPelanggan->last_name }}"
    • value="{{ $dataPelanggan->email }}"
    • value="{{ $dataPelanggan->phone }}"
    • value="{{ $dataPelanggan->birthday }}"
    • untuk pilihan Gender memiliki cara yang berbeda dalam memberikan value

Silahkan lengkapi function store() dan update() dengan rule validasi berikut:

  • first_name wajib diisi.
  • last_name wajib diisi.
  • birthday wajib diisi dan harus berupa tanggal.
  • gender wajib diisi dan hanya boleh bernilai Male atau Female.
  • email wajib diisi dan harus dalam format email yang valid.
  • phone wajib diisi dan harus berupa angka (numeric).

Jangan lupa untuk menampilkan informasi error tersebut di form create dan edit

  • value="{{ old('first_name') }}"

Pada form yang ada diedit.blade.php, terapkan repopulate form. Contoh:

  • value="{{ old('first_name', $dataPelanggan->first_name) }}"
